# ✨ AstraChan

AI-powered **AstraChan** experience created with **ChatGPT, Gemini, and Claude**.

AstraChan is an AI character project where users can interact with, generate, and experiment with custom AI-powered content, personalities, memes, visuals, and crypto-themed scenarios.

## Files

* `index.html` — the website frontend
* `api/generate.js` — the backend that handles AI generation
* `vercel.json` — Vercel configuration

## Deploy to Vercel

1. Upload this folder to a GitHub repository
2. Import the repo on [Vercel](https://vercel.com)
3. Add your required API keys as environment variables in Vercel project settings
4. Deploy!

## How it works

1. User enters a prompt for AstraChan
2. AI models generate a custom AstraChan response, dialogue, meme, or scenario
3. Optional generation APIs can create additional media
4. The final result is displayed directly on the website
